FB Group Listings

Chrome Extension Settings

Anthropic API Key

This extension uses Claude AI to extract structured listings from Facebook posts. You need an API key from console.anthropic.com. Your key is stored locally in your browser and never sent to any server other than Anthropic's API.

Usage Notes

• Navigate to any Facebook group page to activate the sidebar.
• Click Generate Listings to extract and classify posts via AI.
• Results are cached per group — use Refresh to re-process.
• Each run processes all visible posts in batches of 10.
• Scroll down the group feed before generating to include more posts.
